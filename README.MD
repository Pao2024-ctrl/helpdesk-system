# Librería de Componentes UI (Design System)

## Descripción

Este proyecto consiste en el desarrollo de una Librería de Componentes UI para un sistema Help Desk. El objetivo es crear componentes reutilizables que mantengan una apariencia visual consistente y faciliten el desarrollo de interfaces web.

## Componentes Implementados

### Botones
- Botón Primario (Naranja)
- Botón Secundario (Verde)
- Botón de Acción Crítica

### Formularios
- Campos de texto
- Campos de correo electrónico
- Área de texto
- Listas desplegables

### Cards
- Tarjetas para visualizar información de tickets.

### Badges
- Prioridad Alta
- Prioridad Media
- Prioridad Baja

## Tecnologías Utilizadas

- HTML5
- CSS3
- Responsive Design
- Variables CSS

## Responsive Design

Se implementó diseño adaptable mediante Media Queries (`@media screen and (max-width: 768px)`), permitiendo que la interfaz se visualice correctamente en computadoras, tabletas y dispositivos móviles.
